# カレンダーアプリ(仮)
## URL
https://calendar-dsr.pages.dev/  
このURLからアプリケーションを利用することが可能です
## コンセプト
一般的なカレンダーとは異なり、予定をタスク単位で管理し、各日にどの程度の負荷がかかっているかを可視化することで、予定に関する意思決定を支援します。
## 主な機能
### 負荷の可視化
タスクの作業時間に加えて、身体・精神・認知の負荷を設定できます。
各日の予定を負荷率として表示することで、予定の詰め込みすぎや、負荷が集中している日を確認できます。
### シーン機能
シーンを作成することで、独立したカレンダーを複数作成し、それぞれを比較表示できます。
例えば「大会Aに出る場合」と「ハッカソンBに出る場合」で、予定や負荷がどのように変わるかを比較するといった使い方を想定しています。
現在の予定を直接変更せずに複数の案を試し、比較してから採用する予定を決められます。
### 最適化機能
任意のシーンに対して最適化を実行できます。
最適化は、移動可能なタスクを対象として、期限や依存関係を守りながら、日ごとの負荷の超過や偏りが小さくなるように再配置する機能です。
