# カレンダーアプリ(仮)

https://calendar-dsr.pages.dev/

## 利用方法

1. 主シーンから「コピー上で編集」を選び、副シーンを作ります。
2. 副シーンにタスクを追加し、期間、必要時間、負荷、配置方法を入力します。
3. カレンダーで日ごとの予定と負荷を確認します。
4. 必要に応じて主シーンと副シーンを重ねて比較し、最適化を実行します。
5. 内容が決まったら、副シーンを主シーンへ反映します。

## 主な操作

- 日付を選ぶと、その日の負荷とタスクを確認できます。
- 「一覧」ではタスク名の検索、タスクとプロジェクトの追加・編集ができます。
- 「シーン」では表示切替、複製、名前変更、主シーンへの反映、削除ができます。
- 「最適化」では本日から3か月後までの柔軟タスクを再配置します。
- 「設定」では週の開始曜日、1日の上限、負荷プリセットを変更できます。
- 「設定」ではISO週番号の表示・非表示も切り替えられます。
- 負荷のカスタム値とプリセット値はスライダーで調整できます。
- PCでは操作メニューが常に表示され、編集画面でも対象週を確認できます。
- 上部のUndoボタンから直前の保存操作を取り消せます。

詳しい操作は [操作ガイド](USER_GUIDE.md) を参照してください。

予定と設定は使用中のブラウザに保存されます。別の端末やブラウザには自動で共有されません。
