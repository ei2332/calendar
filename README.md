# カレンダーアプリ(仮)

カレンダーアプリ(仮)は、作業時間だけでなく身体・精神・認知の負荷も見ながら、予定を複数のシーンで比較・調整する静的Webアプリです。

**公開URL:** [https://calendar-dsr.pages.dev/](https://calendar-dsr.pages.dev/)

> [!NOTE]
> このプロジェクトでは、コード作成、改善、テスト、ドキュメント整備に生成AIを利用しています。最終的な仕様判断と公開判断はプロジェクト管理者が行います。

## 特徴

- 主シーンを現在の予定、副シーンを編集案として管理
- 最大2シーンを同じカレンダー上で比較
- 作業時間、身体、精神、認知の4軸で日別負荷を表示
- 固定タスクと柔軟タスク、自動配置と手動配置に対応
- 期限と負荷を考慮し、本日から3か月後までを最適化
- タスク検索、プロジェクト、依存関係、凍結、負荷プリセットに対応
- サーバーAPIを使用しない完全な静的アプリ
- 任意のサブパスから配信できる相対アセット構成

## 使い始める

1. 配信された `index.html` をブラウザで開きます。
2. 主シーンは直接編集せず、「コピー上で編集」またはシーン画面の複製ボタンから副シーンを作ります。
3. 副シーンへタスクを追加し、カレンダーで負荷を確認します。
4. 必要に応じて最適化や主シーンとの比較を行います。
5. 内容が確定したら、副シーンを主シーンへ反映します。

画面ごとの詳しい手順は [操作ガイド](USER_GUIDE.md) を参照してください。

## データの保存

データは利用中のブラウザの `localStorage` に保存されます。サーバーやGitHubには送信されません。

- 端末、ブラウザ、ブラウザプロファイルが異なるとデータは共有されません。
- サイトデータやブラウザデータを削除すると、保存内容も失われます。
- 現在の公開版にはクラウド同期とエクスポート機能がありません。

重要な予定の唯一の保管先として使用しないでください。

## 静的配信

このブランチのルートにはビルド済みファイルが配置されています。一般的な静的ホスティングやnginxから、そのまま配信できます。

現在の公開先はCloudflare Pagesです。

- URL: [https://calendar-dsr.pages.dev/](https://calendar-dsr.pages.dev/)
- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `.`

アセットURLは相対パスのため、ドメイン直下でも `/calendar/` のようなサブパスでも動作します。

## 対応環境

JavaScript、Web Storage、CSS Gridを利用できる現行の主要ブラウザを想定しています。スマートフォンとPCの両方に対応します。
